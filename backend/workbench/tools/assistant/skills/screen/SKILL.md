description: 全市场条件选股与今日市场宽度
when_to_use: 用户问「哪些股票满足某条件」或今天市场整体强弱
---

**筛选域口径**。选股是**昂贵操作**（免注册不可用；全市场扫描数万 EC）。

纪律：
- 先确认用户条件再执行；条件要翻译成 XS 表达式（&& / ||，不要 and/or/not）。
- 指标码不确定时先 `catalog_search` 查目录，**不要猜码**。
- 默认小额试探（limit 20-30）；用户没确认大清单前不放大 limit。
- 排序方向别弄反：`desc` 默认从大到小；找低 PE / 低估值时必须 `desc=false`。
- 默认非负守卫：布尔标志位（`$IS_*`）跳过，商誉/有息负债等零值合法；
  不要手动关掉，除非用户明确要包含负值。
- 市场宽度/涨跌榜是廉价的，问「今天市场怎么样」优先用它们。
- 结果是数据不是推荐；不排序出「最好买的股票」这类结论。
