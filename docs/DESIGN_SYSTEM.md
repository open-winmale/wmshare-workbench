# UI / UX 设计规范

> 目的：保证 UI 质量与风格统一。所有条款可核对；标 `manual` 的进评审清单。
> **移植 vs 自定的边界是本文件的第一等公民**：12 色图表调色板与数字等宽字体族的**数值**
> 来自对标物公开源码（见 `docs/ADR/001`）；语义色、UI 字体栈、阴影、间距、圆角、动效、
> 字号阶梯由本项目自定（商务主题见 `docs/ADR/002`），此后即为本仓契约。

> **改造提案（未生效）**：UI 商务风（钉钉式）诊断与 token/组件改造清单见
> [UI_BUSINESS_THEME.md](UI_BUSINESS_THEME.md)。现行契约仍是本文件；若提案获批，
> 需先立 ADR-002 并同步 `LICENSE` / `README` / `tokens.css` 的来源说明。

## 1. 设计原则（四条，冲突时按序号优先）

1. **口径优先于美观**——每个数字都能回答「什么时候的 / 什么单位 / 全不全」。
2. **不骗人**——缺是缺、旧是旧、不全是不全；绝不插值填满、绝不用 `0` 冒充缺失。
3. **成本可见**——花钱的操作必须事前告知，且可取消。
4. **不替用户判断**——呈现事实与统计，不下买卖结论、不给目标价。

### 2.2 图表调色板（**移植**，12 色，顺序不可变）

```
--wb-chart-1:  #f5ae39    --wb-chart-5:  #4680f1    --wb-chart-9:  #5ed9e6
--wb-chart-2:  #3fb1ea    --wb-chart-6:  #b98749    --wb-chart-10: #f67f2f
--wb-chart-3:  #9c51cc    --wb-chart-7:  #b7c9fc    --wb-chart-11: #b7a1f5
--wb-chart-4:  #ffb8df    --wb-chart-8:  #e45cbe    --wb-chart-12: #f0d947
```

**为什么顺序不可变**：这个顺序经**相邻对色觉障碍可辨性校验**，重排会破坏该性质。
第 i 条序列固定用 `--wb-chart-(i+1)`。

色盲变体覆盖：`chart-2 #3bcabb`、`chart-5 #a4d854`、`chart-10 #e74783`。

### 2.3 字体

- **UI 家族（自定）**：`--wb-font-sans`，`PingFang SC / Microsoft YaHei / Noto Sans CJK`
- **数字/代码家族（移植）**：`--wb-font-mono`，`'JetBrains Mono','Consolas',monospace`
- **字号阶梯（自定）**：`11 / 12 / 13 / 14 / 16 / 20 / 28`（`--wb-fs-1` … `--wb-fs-7`）
- **行高（自定）**：`1.2`（紧凑数字）· `1.5`（正文）
- **字重**：`400` / `500` / `600`（不用 `700`，等宽粗体在小字号下发糊）

**铁律**：UI 正文用无衬线，但**数字、代码、标识符必须等宽**——否则竖向小数位
不齐，这是财经界面最容易失分的地方。`DataTable .num`、`KpiStrip .value` 已显式
用 mono；页面内零散数字的收口属 P1。

### 2.4 间距与圆角（**自定**，4px 基准）

- 间距：`2 4 6 8 12 16 20 24 32 40 48`（`--wb-sp-1` … `--wb-sp-11`）
- 圆角：`4 6 8 12 999`（`--wb-r-1` … `--wb-r-5`；控件 4–6，卡片 8–12，胶囊只给状态）
- **禁止** `7px`、`13px`、`18px` 这类非标值（`check_tokens` 拦常见违规）

### 2.4b 阴影与布局（**自定**）

- 卡片：`--wb-shadow-1`（亮色 `0 1px 2px rgba(29,33,41,.04), 0 2px 8px rgba(29,33,41,.04)`）
- 浮层：`--wb-shadow-2`
- 外壳：`--wb-topbar-h:56px` · `--wb-nav-w:220px` · `--wb-content-pad:24px`
- **阴影只能写在 `tokens.css`**（`check_tokens` 禁止其他文件出现 `rgba()`）。

### 2.5 动效（**自定**）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--wb-dur-fast` | `120ms` | hover / 焦点 |
| `--wb-dur-base` | `200ms` | 展开 / 折叠 |
| `--wb-dur-flash` | `600ms` | 行情闪烁淡出 |
| `--wb-ease` | `cubic-bezier(.2,0,0,1)` | 统一缓动 |

**必须尊重 `prefers-reduced-motion: reduce`**：全部降为 `0ms`，闪烁改为静态边框。

### 2.6 层级（**自定**）

`--wb-z-sticky:10` · `--wb-z-dropdown:100` · `--wb-z-overlay:1000` · `--wb-z-toast:2000`
**禁止**随手 `z-index: 9999`。

## 3. 数字与单位呈现（财经工作台最容易翻车处）

> 底层契约沿用 wmshare：**率=小数、额=元、量=股**。格式化**只发生在 UI 层**，
> 数据层永远传原始值。

| 类型 | 规则 | 正例 | 反例 |
|---|---|---|---|
| 价格 | 2 位小数 + 千分位 | `1,234.56` | `1234.5600` |
| 涨跌幅 | 带符号 2 位 + `%` | `+2.31%` `-0.87%` | `0.0231` |
| 比率 | 底层小数 → 显示百分比 | `0.03 → 3.00%` | `0.03%` |
| 金额（自动缩量） | `<1万` 原值 / `<1亿` 万 / `≥1亿` 亿 | `8,512.00` · `1.23万` · `45.67亿` | 一律 `123456789.00` |
| 成交量 | 按列声明口径，手=÷100 | `12.34万手` | 混用股与手 |
| 市值 | 亿元固定 | `1,234.00亿` | |
| **缺失** | `—`（全角破折号） | `—` | `0` / `N/A` / 空白 |
| **零值** | `0.00`（**0 是数据**） | `0.00` | `—` |
| **负零** | 归一为 `0.00` | `0.00` | `-0.00` |
| 排序 | **永远用底层数值键** | `1.2万` 按 `12000` 排 | 按字符串排 |

**三条额外的「不许静默」**：

1. **不全要标**：合计只覆盖 18/20 只时必须显示 `18/20`。
2. **旧要标**：`as_of` 与当前差超过阈值 → 打 `STALE` 角标 + 期龄。
3. **估算要标**：任何非直接取自源的数字（如 CAGR、年化）必须带口径注脚。

## 4. 表格规范（8 条）

1. 数值列**右对齐** + 等宽 + **独立数值排序键**（`1.2万` 按 `12000` 排）。
2. 斑马纹 `--wb-row-alt`；悬停 `--wb-bg-hover`；选中 `--wb-accent-bg`。
3. 表头吸顶（`--wb-z-sticky`）；排序指示器三态（无 / 升 / 降）。
4. 单元格闪烁：`flash ∈ [-1,1]`，符号即方向，**零与缺值不闪**，`--wb-dur-flash` 淡出。
5. 列最小宽度按内容类型预设；超宽省略号 + tooltip 显示全值。
6. 行内可视化三选一：迷你线（≤20 点）、条形（占列宽比例）、区间条（低-高 + 当前点）。
7. **分页优先于无限滚动**（便于「第 N 页」复现与截图比对）。
8. **空表头不许省**——列结构本身是口径的一部分。

## 5. 图表规范（8 条）

1. 12 色顺序固定，第 i 条序列用 `--wb-chart-i`，**不许重排**。
2. 涨跌色只用 `--wb-up` / `--wb-down`，**不许用调色板色冒充涨跌**。
3. 缺值**断线留白**，绝不补 0。
4. Tooltip 必须含 `as_of` 与单位。
5. 坐标轴千分位 + 单位后缀；双轴必须两侧各自标注，否则禁止双轴。
6. 禁止：3D、系列渐变、阴影、无意义动画。**截断纵轴必须显著标注** `⊘ 纵轴非零起点`。
7. 单序列热力用 `--wb-seq-low → --wb-seq-high`。
8. 时序默认左旧右新；K 线遵循 A 股习惯（红涨绿跌）。

## 6. 五态规范（每个面板强制全实现）

| 态 | 视觉 | 必有内容 |
|---|---|---|
| **loading** | 骨架屏（**非 spinner**），保持布局不跳动 | 预计耗时或进度 |
| **empty** | 五级压缩 `Full → NoGlyph → NoDetails → Inline → TitleOnly` | 原因 + 下一步操作 |
| **error** | **保留上次数据** + 顶部错误条 | 错误类别 + `action` 按钮 |
| **stale** | 右上 `STALE` 角标 | 数据期龄 + 阈值 |
| **partial** | 角标 `18/20` | 缺了哪几只、为什么 |

**铁律**：**有数据时出错绝不白屏**——保留 last-known-good，只加角标。
这是本项目最重要的一条交互约束：投研场景里，「看到可能旧的数据」远好于「什么都看不到」。

`action` 取值与 wmshare 错误分级对齐：
`retry`（可重试）/ `topup`（需充值）/ `config`（需配置）/ `fix_input`（输入错）/ `report`（该报 bug）。

## 7. 布局

- 12 列栅格，间距 `--wb-sp-5`（12px），容器内边距 `--wb-sp-6`（16px）。
- 断点：`<1280` 单列堆叠 · `1280–1679` 两列 · `≥1680` 三列 · `≥2400` 四列。
- 面板最小 `280×180`；KPI 瓦片最小宽由字号推导（约 20 字符）。
- **KPI 丝带均衡分配**：能纳 5 列时 7 个瓦片排 `4+3`，**不许** `5+2`。
- 面板可折叠；折叠后保留标题栏，**不卸载状态**（用 `v-show` 而非 `v-if`，
  除非该面板显式声明 `unloadable`）。

## 8. 键盘与焦点

| 操作 | 键 |
|---|---|
| 全局命令面板 | `⌘K` / `Ctrl+K` |
| 聚焦搜索 | `/` |
| 面板内移动 | `↑` `↓` |
| 展开 / 折叠 | `Enter` / `Space` |
| 关闭面板 | `Esc` |
| 刷新当前面板 | `R` |
| 切换主题 | `⌘⇧L` / `Ctrl+Shift+L` |

焦点环统一 `2px var(--wb-accent)` + `offset 2px`，**永不移除 `outline`**。
所有可交互元素必须有 hover / active / focus-visible / disabled 四态。

## 9. 无障碍

- 正文对比度 ≥ `4.5:1`，大字（≥18.66px 或 ≥14px 粗体）≥ `3:1`，**双主题各测**。
- **颜色不得作为唯一信息载体**：涨跌必须同时有符号（`+`/`−`）；状态必须同时有文字。
- 点击目标 ≥ `24×24px`。
- 全面板可键盘到达；模态有焦点陷阱与 `Esc` 关闭。
- 图表提供「数据表」替代视图。

## 10. 组件 API 约定

| 约定 | 规则 |
|---|---|
| Props | 一律类型化；枚举用联合字面量，不用裸字符串 |
| 双向绑定 | 只用 `v-model`（单值）；多值用 `v-model:xxx` |
| 事件 | `kebab-case` 动词过去式（`row-selected`），禁止 `change1` 之类 |
| 插槽 | 命名槽 `header` / `footer` / `actions` / `empty` |
| 尺寸 | 只接受 `size="sm|md|lg"`，**不接受裸像素** |
| 主题 | 组件内**零硬编码色值**，全部 `var(--wb-*)` |
| 密度 | 表格支持 `density="compact|comfortable"`（13px / 14px） |

## 11. 文案规范

- 数字永远带单位与口径。
- 错误文案三段式：**发生了什么 → 为什么 → 你可以做什么**。
- 付费操作文案必须含 EC 区间与「取消不收费用」。
- **禁词**：`建议买入` / `建议卖出` / `目标价` / `必涨` / `稳赚` / `定投发车` / `抄底` / `满仓`。
- 每个数据页脚注固定：`数据来自 wmshare，最终以上市公司公告为准；本工具不构成投资建议。`

## 12. 反模式清单（评审直接用）

| 反模式 | 为何禁 |
|---|---|
| 红绿无正负号 | 色盲不可用 |
| 用 0 填充缺失序列 | 伪造数据 |
| 涨跌幅显示 `0.0231` | 逼用户心算 |
| 合计不标覆盖比例 | 静默失真 |
| loading 用 spinner 且不占位 | 布局跳动 |
| 出错清空内容 | 丢失 last-known-value |
| 组件内写 `#ff0000` | 令牌失效、主题切换坏 |
| 长操作无进度与取消 | 用户不知在等什么 |
| 无限滚动代替分页 | 无法复现与比对 |
| 用调色板色表示涨跌 | 语义混淆 |
| 纵轴截断不标注 | 视觉夸大 |

## 13. 自定条款的效力

§2.3–§2.6（字号阶梯、行高、间距、圆角、动效、层级）与 §7–§10 中标注「自定」的数值，
由本项目确定并随后成为契约。修改它们属于**设计系统变更**，需要：

1. 改 `quality/baselines/tokens.json`
2. 更新全量视觉基线截图
3. 在 `PROGRESS.md` 记一条 `type=refactor, scope=design-system` 的工作项

理由：令牌一旦被组件消费，改它就是全局重构；不设门槛会导致「每次改需求顺手调个颜色」的慢性腐化。
